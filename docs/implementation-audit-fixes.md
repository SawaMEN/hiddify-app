# Исправления аудита реализаций

Ветка: `fix/implementation-audit-2026-10-05`.
База изменений: `68732765129496d0e39f94f15f085ba2552998e7` (main).
Исходный аудит: `4729f3d193fe1afea4426bb087aab8845d47a884`.

Обработаны все 99 пунктов основного списка: для 98 внесены изменения,
пункт 021 снят как ошибочный. Это не 200 подтверждённых ошибок: 23 гипотезы
из прежнего отчёта не включены в это число и не объявляются исправленными.
Пункт 033 устранён удалением неподдерживаемого выбора из интерфейса, без добавления несуществующего поля API ядра.

## Проверки

- Flutter 3.47.5 / Dart 3.13.4: pub get, slang, build_runner успешно.
- Полный flutter test: **48 тестов прошли** (26 существующих и 22 добавленных).
- flutter analyze --no-fatal-infos --no-fatal-warnings: **0 ошибок**, код завершения 0. Lint warning/info остаются; строгий анализ без этих флагов не объявляется чистым.
- Проверены URL/CIDR/диапазоны, filename, nullable/list preferences, выбор релиза, монотонность timestamp, запись правил и её отказ, DAO профилей/приложений, JSON widget и полный settings round-trip.
- Android: MethodChannel stop проверен с fake binary messenger (false/null/exception/true). Изменения Kotlin просмотрены статически. APK и поведение на устройстве не подтверждены: закреплённый core asset 609473425 возвращает HTTP 404; SDK Manager не находит platforms;android-37; Gradle wrapper не скачивается из JVM в этом окружении (Network is unreachable). Закреплённые версии зависимостей не подменялись.
- Для VPN, DNS, лицензий, stream reconnect и динамического Android notification остаётся обязательная проверка на устройстве с доступным ядром.
