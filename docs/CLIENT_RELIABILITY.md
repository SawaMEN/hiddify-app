# Надёжность клиента и новые функции

Изменения построены поверх актуального Material UI интерфейса. История версий подписки не добавлена.

| Функция | Поведение |
|---|---|
| Статус соединения | Запуск VPN и доступность интернета показаны отдельно. HTTP-проверка идёт только через локальный прокси, без прямого обхода. |
| Восстановление | Неожиданная ошибка запускает максимум пять попыток через 2, 4, 8, 16 и 30 секунд. Ручное отключение, отмена и выключение настройки отменяют таймеры и устаревшие операции в очереди. Минутное стабильное соединение сбрасывает счётчик. |
| Сеть Android | Смена сети обрабатывается корутиной с отменой устаревших событий; нет блокирующего Thread.sleep. Обновление интерфейса будит ядро; блокировка callback сохраняет защиту от обращения к уничтоженному ядру. |
| Диагностика | Проверяются нижележащая сеть, системный DNS, TCP-доступность известного сервера и HTTP через VPN. UDP и цепочки не объявляются исправными на основании TCP. |
| Отчёт | Пользователь видит JSON перед отправкой. Ссылки, адреса, UUID, пути и именованные секреты очищаются. Очистка произвольного текста — best effort, поэтому отчёт нужно просмотреть. |
| Импорт | Ядро проверяет подготовленный файл до подтверждения. Предпросмотр считает найденные серверы, дубликаты, неизвестные типы и изменения DNS/маршрутов; HTTP отмечается отдельно. Подтверждённый файл не загружается повторно. Счётчики являются оценкой для JSON, ссылок и YAML. |
| Загрузка | 8 МиБ на файл и общий объём вложенных подписок; не больше 128 вложенных URL, четыре параллельных запроса. Отдельный запрос ограничен 60 секундами и поддерживает отмену. Чтение файла асинхронное, разбор заголовков и предпросмотра выполняется через compute. |
| HTTP-кэш | ETag/Last-Modified и восстановление текущего содержимого при 304. Обновлённые заголовки ответа имеют приоритет. Не больше 32 текущих файлов, URL не хранится в имени. Старые версии не сохраняются. |
| Серверы | Поиск по имени/типу. Автоматический режим по умолчанию выключен; учитывает EWMA задержки, ошибки, свежесть и минимум три успешные проверки. Для смены требуется устойчивое улучшение минимум на 20% и 50 мс либо три ошибки текущего сервера. Интервал между сменами — две минуты. Ручной выбор выключает автоматику и имеет приоритет в общей очереди. |
| Проверка маршрута | Правила пользователя проверяются по порядку; домены/IP объединяются через OR, порт/пакет/сеть — AND. Более раннее неопределённое правило не пропускается ради позднего совпадения. DNS, rule sets, процесс и определённый через sniffing протокол требуют дополнительных данных. Сложные regex не исполняются. Это объяснение пользовательских правил, а не полная симуляция ядра. |
| Android Always-on | Ссылка на системные настройки, состояние работающей службы на Android 10+, запуск системной службы до Flutter, учёт отзыва разрешения и ручной остановки. Системная блокировка может лишить исключённые приложения интернета. |
| Интерфейс | Мобильные вкладки: главная, серверы, правила, настройки. Старые ссылки серверов/правил сохранены, профили доступны из настроек. Скорость обновляется максимум раз в секунду; проверки и статистика приостанавливаются в фоне. Существующие настройки эффектов и системные цвета сохранены. |
| Телеметрия | По умолчанию выключена. Ранее явно сохранённое согласие сохраняется. Трассировка взаимодействий выключена; исключения, контексты, breadcrumbs и дополнительные поля очищаются перед отправкой. |
| Обновления | GitHub API и appcast направлены в SawaMEN/hiddify-app. Черновики, неподходящие платформе артефакты и повреждённые версии пропускаются. Stable/dev разделены; stable CI публикует собственный ARM64 appcast и SHA256SUMS. Минимальная система в feed — Android 7 / SDK 24, совпадает с текущим Flutter build. |

## Проверка

```sh
flutter pub get
dart run slang
dart run build_runner build
flutter analyze --no-fatal-warnings --no-fatal-infos
flutter test
dart tool/check_async_runtime.dart
python3 tool/test_appcast.py
```

UI-тесты включают 320 px / текст 2× и RTL. Отдельные проверки покрывают 304, повреждённый/отсутствующий кэш, размер ответа, запрет прямого fallback, ограничение повторов/ручную отмену, выбор сервера, маршруты и очистку сериализованной телеметрии. Native Android compilation проверяется обычным PR CI. Ядро собирается из закреплённых core/kernel подмодулей; удалённый draft-архив больше не используется.

## Проверка на устройстве

Нужно подтвердить Wi-Fi → мобильная сеть → отсутствие сети → восстановление, сон/возврат приложения, ручное отключение во время повтора, запуск Always-on после перезагрузки, блокировку без VPN и исключённые приложения. Проверить VPN с собственными TCP/UDP серверами и импорт реальной подписки. Эти сценарии и измерения батареи/FPS на физическом устройстве не проверены локальными тестами.

TCP/DNS диагностические операции имеют таймауты; системный DNS не подтверждает DNS внутри туннеля. Отчёт намеренно не включает сырые профили или логи. Автоматический выбор использует уже полученные URLTest измерения и не запускает дополнительные массовые тесты.
